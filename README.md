# rock-paper-scissors

A web-based implementation of the classic Rock Paper Scissors game built as part of The Odin Project curriculum.

## Project Evolution
This project originally started as a simple, text-based game played directly inside the browser's developer console. It has since evolved into an interactive graphical user interface (GUI) built with dynamic DOM manipulation, HTML, and CSS.

## Features
- **Interactive UI:** Play directly on the page using designated action buttons instead of browser prompts.
- **Dynamic DOM Updates:** Live round outcomes and scores update on the screen in real-time.
- **Game-Over Control:** Game plays to 5 points. Buttons automatically disable once a winner is declared to prevent post-game scoring.
- **Refined Layout:** Structured container layout featuring a styled dark arcade design palette.

## Tech Stack
- **HTML5:** Semantic structure and content layout.
- **CSS3:** Custom styling, themes, and flexbox alignment.
- **JavaScript (ES6):** Game logic, score tracking, event handling, and DOM manipulation.

## How to Play
1. Open `index.html` in your browser.
2. Select **Rock**, **Paper**, or **Scissors** to play a round against the computer.
3. The first player to reach **5 points** wins the match!
